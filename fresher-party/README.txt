Fresher Party site
==================
Files
  index.html   The complete site (one self-contained file).

How to use
  1. Open index.html in a browser (internet needed: it loads React, Tailwind and htm from online libraries).
  2. To put it online, upload the folder to Netlify Drop, GitHub Pages, Vercel or Cloudflare Pages.

Important
  Sign-in, shared editing and change history only work on the claude.ai link,
  because they use claude.ai's account and storage features.
  When opened from this zip the site shows the original itinerary in view-only mode.
  Print / Save PDF, Dark mode and the display toggles still work.
