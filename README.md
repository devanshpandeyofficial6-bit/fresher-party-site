# 🌟 Freshers 2026 - Event Portal & Itinerary Management

Official web application for **Freshers 2026** (Friday, October 16, 2026).

## 🚀 Features
- **🔐 User & Admin Authentication**: Email/Password Sign up & Login.
- **👑 Super Admin Dashboard**: Admin account (`devanshpandeyofficial6@gmail.com`) to manage user permissions (`Can Edit` vs `Viewer`).
- **📋 41-Segment Itinerary**: Complete timeline with anchor links, performances, 4 ramp rounds, open slots, crowning, BTS video, and batch distribution.
- **👥 Department-wise Committee Roster**: Real-time team roster with roll numbers and in-place Add/Delete/Edit functionality.
- **🖨️ Clean Black & White PDF Export**: Print-ready format accessible via `Ctrl + P` or the Export button.
- **🌙 High-Contrast Dark Theme**: Fixed theme for stage & management readability.

## 🌐 Deploy to Render
1. Push this repository to GitHub.
2. Go to [Render Dashboard](https://dashboard.render.com/) -> **New +** -> **Static Site**.
3. Select your repository.
4. Set **Publish Directory** to `./` (or leave as detected from `render.yaml`).
5. Click **Create Static Site**.
